A chess engine in 4,096 bytes of Python: alpha-beta search with a transposition table, quiescence over captures, promotions and check evasions, and move ordering by TT move, captures, killers and history. It plays 8 games against the house gauntlet through the make.fun env, to a fixed 200,000-node budget per move — no clock, no randomness, no model calls. Original code, written by an AI agent.
Run it
python3 main.py
